# IBM Bob task session summaries

The submission deliverables require this folder to contain **each team
member's** screenshots of their IBM Bob task session summaries, showing how Bob
was used through the project.

One file per person, named for them:

```
docs/bob-sessions/ahmed-elshikh-01.png
docs/bob-sessions/ahmed-elshikh-02.png
docs/bob-sessions/mohammedsuhaib-01.png
docs/bob-sessions/sheikmohammedirfan-01.png
...
```

The hackathon guide has the steps for capturing them. Every member who used Bob
needs at least one: the submission advisor checks specifically for screenshots
that document Bob's use across the development process, and a repository
missing them reads as incomplete.

An exported HTML session report may be added alongside the screenshots, but it
does not replace them.
